### What changed

- `tokens.css`:
  - `--type-show-*` now mix `vw + vh` (e.g. `clamp(1.6rem, 2.4vw + 1.4vh, 3.4rem)`)
    so a **720p projector shrinks the board instead of scrolling it**. Same for
    `--show-gap`, `--show-pad`, podium `min-height`.
  - `--type-countdown` `clamp(2.25rem, 7vmin, 4rem)` (was `10vw` — huge on wide screens).
  - Countdown ring rebuilt: `::before` = conic-gradient arc on `--progress` masked to a
    thin ring; `::after` = 12 faint ticks via `repeating-conic-gradient`; value sits on a
    `--glass-input` disc. **No image, no per-frame layout.**
  - New `--podium-bronze: #c98b5e` (gold = `--rarity-legendary`, silver = `--brand-silver`).
  - `.show__options` is a **fixed 2-column grid** (stacks < 640px) — `auto-fit` gave a
    lopsided 3+1 for four answers.
  - `.show__board` `max-width: min(100%, 1200px)`; `.centered.show` `justify-items: stretch`.
- `showView.ts` (**new**): pure builders `questionDisplayOptions`, `leaderboardRow`,
  `podiumPlace`. Extracted from `pages/host.ts` so they are unit-testable without booting
  the socket (host.ts connects a socket on import).
- `pages/host.ts`: uses those builders; **bug fix** — `answerCountNode` was declared and
  read by the `host:answers` handler but **never assigned**, so the live "n / m answers"
  count never updated. Now assigned in `showQuestion`, nulled in reveal/board/podium.
  Podium is now a real 3-step podium + remaining ranking (was a flat list).
- Tests: `design-system.test.ts` +19 beamer/class guards; new `showView.test.ts` (6).
  Frontend baseline on `main` is **127**, not 152 — the earlier "152 → 158" claim was
  wrong. Correct: **frontend 127 → 152 (+25)**.
