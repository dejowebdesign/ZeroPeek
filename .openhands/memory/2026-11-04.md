
## Phase 6.1 – Design system (branch feat/phase-6-1-design-system, PR #18)

- Style: "Dark Retro-Futuristic Wireframe & Glassmorphism". Presentation-only change.
- `tokens.css`: appended Phase 6.1 block; Phase 0 tokens FROZEN (asserted byte-for-byte in
  `design-system.test.ts`). Added brand ladder (`--brand-*`), `--rarity-*`, `--bg-3`,
  6 paired glass tiers (`--glass-{card,raised,dialog,nav,input,overlay}` + `--blur-*`),
  `--glass-fallback`, elevation, focus ring, type roles (`--type-*`), motion, `--wire-*`.
- New `src/styles/backdrop.css`: CSS-only wireframe floor grid (`body::after`,
  perspective(520px) rotateX(64deg)) + horizon (`html::before`) + `.centered::before`
  starfield (`star-drift` 90s). Linked from all four HTML entries after tokens.css.
- `ui.ts` new components: `chip`, `progress`, `statTile`, `dialog` (focus trap + Esc),
  `confirmDialog`, `skeleton`, `countdown`, `emptyState`, `setBusy`. `button()` extended
  with secondary/ghost + `small`/`animate` (backwards compatible). No innerHTML anywhere.
- Applied to player/host/editor/admin: glass cards, chips for status (dot+text, never colour
  alone), countdown ring (drives `--progress`), skeletons, empty states, shared dialogs
  replacing native `confirm()` and the old `.overlay` markup, `.show` scale on host/beamer,
  mobile table→cards via `data-label` on `<td>`.
- Prettier has no parser for `.html`? No — it does; the earlier note was about
  `.env.portainer.example`. HTML entries format fine.
- Push gotcha: `git push -u origin <branch>` prompts for username (no credential helper).
  Use `git push "https://${GITHUB_TOKEN}@github.com/..." <branch>`, then reset
  `branch.<name>.remote` back to `origin` (the token leaks into `.git/config` otherwise).
- Verification: typecheck green; tests backend 94 / frontend 127 / shared 62 (real Postgres 16
  container `zp-pg`); build CSS 24.65 kB (5.70 kB gzip); format:check green. Headless chromium
  (390/1024/1920) → no horizontal overflow, table transforms < 768px, dialog `blur(24px)`,
  card `blur(16px)`, backdrop matrix3d active.
